# Installation

## Quick start

Install Docker with Compose, then run:

```sh
git clone https://github.com/acidmiku/zarr.git
cd zarr
docker compose up -d --build
```

Open [Zarr](http://localhost:9876). Quick start lets you enter a TMDB key, add optional connections, or open the library immediately. Every choice remains editable in Settings. No `.env` file is required.

The included stack runs Zarr, SABnzbd, qBittorrent, and a short initialization job. On a fresh installation, that job generates unique downloader credentials, configures shared paths, and supplies the connections to Zarr. It never replaces an existing downloader configuration.

| Interface | Local address | Address used by Zarr in Docker |
| --- | --- | --- |
| Zarr | http://localhost:9876 | — |
| SABnzbd | http://localhost:8085 | http://sabnzbd:8080 |
| qBittorrent | http://localhost:9090 | http://qbittorrent:9090 |

qBittorrent uses the same internal and published Web UI port because current versions validate the Host header's port. If you customize it, update its `WEBUI_PORT`, published port, and Zarr's saved connection URL together.

The web interfaces bind to localhost by default. To access Zarr from another machine, explicitly adjust the port binding and use your own authenticated reverse proxy; the app does not provide multi-user authentication.

## Add services in Zarr

- **Metadata:** enter and test your TMDB API key or read access token.
- **Usenet:** add a Newznab indexer under Indexers, and add your provider's hostname, TLS port, and login under Usenet servers. NZBGeek and Newsgroup Ninja presets fill non-secret defaults.
- **Torrents:** the bundled qBittorrent connection is ready. Add a supported Rutracker indexer with its login to search torrent releases.
- **Assistant:** enter your OpenRouter key, model ID, and reasoning effort. The default is `moonshotai/kimi-k3` with high reasoning.

See [Configuration](configuration.md) for external downloaders and proxies.

## Storage and upgrades

```
data/
  config/              # SQLite, generated bundled connection credentials, caches
  media/               # Organized movies, tv, anime, music
  sabnzbd-config/      # SABnzbd settings
  qbittorrent-config/  # qBittorrent settings
  usenet/              # incomplete/ and complete/
  torrents/            # Torrent payloads retained while seeding
```

`data/` is excluded from Git and Docker's build context. Keep backups private: the database and downloader configuration contain credentials. Back up these directories before an upgrade; SQLite migrations run automatically.

```sh
git pull --ff-only
docker compose up -d --build
docker compose logs --tail 100 zarr
```

For existing installations, saved settings and downloader configuration are preserved. Enter existing downloader credentials in Settings if they were not generated by this stack. With the bundled qBittorrent service, update a previously saved `http://qbittorrent:8080` URL to `http://qbittorrent:9090`. Keep Zarr's download mounts aligned with paths reported by your download clients. Older SABnzbd installations using `/config/Downloads` need either a shared mount at that exact path or their folders changed to `/data/usenet`.

The anime scoring migration adds separate TRaSH movie/series profiles and keeps existing profiles and library assignments intact. New anime additions choose the matching preset automatically. To enable the new scoring for an existing title, select its preset on the Library detail page. See [Anime quality profiles](anime-quality-profiles.md) for upgrade cutoffs, audio-label limitations, and why library rescans clear uncertain release provenance.
